# 硬币检测与缺陷分级系统（Python + OpenCV）

> 测控专业个人项目 · 以硬币为对象，模拟工业零件视觉质检全流程
> 技术栈：Python · OpenCV · NumPy · openpyxl

## 项目简介

用 OpenCV 传统图像处理实现对硬币的自动化检测：测量真实直径 → 判定圆度与尺寸 → 按偏差分级
（合格 / 轻度 / 中度 / 重度）→ 输出可视化结果图与 CSV/Excel 报表。

完整模拟工业视觉链路：**采集 → 预处理 → 特征提取 → 像素标定 → 判定分级 → 报表输出**。

## 功能特性

- 双模式：批量图片检测 / 摄像头实时检测
- 声明制检测：指定面额，按对应国标尺寸判定
- 像素 → 毫米标定换算
- 四级缺陷分级 + 分级配色可视化（绿/黄/橙/红）
- 批量导出 CSV / Excel 检测报表
- **结果可追溯**：结果图与报表保留原图文件名，未检出目标也单独成行，可逐条回查

## 处理流程

```
读图 → 灰度 → 高斯模糊 → Canny 边缘 → 轮廓筛选 → 特征计算(面积/周长/圆度/直径)
    → 像素→毫米(标定) → 按声明面额判定(圆度+尺寸超差) → 四级分级 → 可视化 + 报表
```

## 快速开始

```bash
pip install -r requirements.txt
cd coin_detect

# 批量模式：检测指定文件夹内图片并导出报表（结果默认输出到 <input>/result）
python main.py --mode batch --coin 1元 --input <图片文件夹>

# 实时模式：摄像头逐帧检测，按 q 退出
python main.py --mode camera --coin 1元
```


| 参数 | 说明 | 可选值 |
| :--- | :--- | :--- |
| `--mode` | 运行模式 | `batch`（默认）/ `camera` |
| `--coin` | 被检面额（必填） | `1元` / `5角` / `1角` |
| `--input` / `-i` | 批量模式：待检测图片文件夹（batch 必填） | 任意路径 |
| `--output` / `-o` | 结果输出文件夹（选填，默认 `<input>/result`） | 任意路径 |

## 检测报表

输出目录内含 `result_NNN_<原图名>.jpg` 结果图与 `coin_detect_report.csv` / `.xlsx`，列如下：

| 序号 | 图片名称 | 面额 | 直径(mm) | 圆度 | 偏差(mm) | 方向 | 严重程度 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |

- **序号与结果图文件名中的 `NNN` 严格一致**，可逐条回查到原图
- 某张图未检出任何目标时，仍输出一行「未检出」，不会从报表中消失

## 判定逻辑

1. **圆度**：`4π·面积 / 周长²`（理想圆为 1.0），低于 `min_circularity` 判形状不合格
2. **尺寸**：`偏差 = 实测直径 − 国标直径`；`超出量 = |偏差| − 允差`
3. **分级**：超出量 ≤0 合格；0~0.3 轻度；0.3~0.6 中度；>0.6 重度（并输出偏大/偏小）

> 分级量用「超出量」而非「绝对偏差」，使不同面额共用同一套分级标准。

## 检测参数

| 参数 | 值 | 说明 |
| :--- | :--- | :--- |
| `ppm` | 10.0 | 每毫米像素数（**待实测标定**） |
| `min_circularity` | 0.9 | 圆度合格阈值 |
| `grade_light` / `grade_mid` | 0.3 / 0.6 | 分级刀口（毫米） |

| 面额 | 标称直径 | 允差 |
| :--- | :--- | :--- |
| 1元 | 25.0mm | ±1.25 |
| 5角 | 20.5mm | ±1.03 |
| 1角 | 19.0mm | ±0.95 |

## 已知局限

- `ppm` 当前为演示假定值，需用已知尺寸物体实拍标定后替换
- 声明制需运行前指定面额；若放错币种，会判为「尺寸严重超差」而非主动防错
- 分级逻辑目前仅在**非硬币**图片上跑通流程；真实硬币数据上的分级准确性（合格/轻度/中度/重度的实际触发）待实测
